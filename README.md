# CHELZ.EXE 💻✨

**Learning. Building. Becoming.**

CHELZ.EXE is my personal portfolio website, created to showcase my projects, document my growth as a Computer Science student, and build my presence as a developer.

Designed with a midnight aesthetic, violet accents, and a clean, modern layout, the website brings together my personal introduction, projects, academic planning, and contact information in one place.

This project is part of my journey into software development — learning by building real things, solving problems, and improving with every project.

## ✨ Features

- **Home page:** An introduction to me and my journey.
- **About page:** More about who I am and what I'm working toward.
- **Projects page:** A collection of my programming and web development projects.
- **Academic planner:** A study timetable and interactive task management system for organizing coursework and tracking progress.
- **Contact page:** A contact form with input validation.
- **Responsive design:** Layouts designed to adapt to different screen sizes.
- **Interactive functionality:** JavaScript-powered features that make the website more than a static portfolio.

## 🛠️ Built With

- **HTML5** — page structure and semantic markup.
- **CSS3** — styling, layouts, responsive design, and visual effects.
- **JavaScript** — form validation, DOM manipulation, and interactive functionality.
- **Local Storage** — saving academic planner tasks in the browser.
- **Git and GitHub** — version control and project hosting.

## 🎨 Design

The visual identity of CHELZ.EXE is built around a dark, modern aesthetic.

- **Midnight:** `#0B0B12`
- **Violet:** `#8B5CF6`
- **Light violet:** `#C4B5FD`
- **Typography:** Inter

The design aims to balance simplicity, personality, and usability while maintaining a consistent experience across the website.

## 🚀 Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone <https://github.com/michellelaniyi/CHELZ-exe>
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

For the best development experience, you can use Visual Studio Code with the Live Server extension.
